맵맵맵 · 모바일 첫 화면 레이아웃 시안

거지맵·야장맵·카카오/네이버/구글 지도 패턴을 참고한 4가지 방향입니다.
각 폰 프레임을 보고, 전체화면으로 보기를 누르면 실제 모바일 풀스크린으로 확인할 수 있어요. 마음에 드는 시안 번호(A/B/C/D)를 알려주세요.
※ 4개 모두 현재 PC 웹과 동일한 기능만 사용 — 배치만 모바일에 맞게 바꿉니다 (검색 등 새 기능 없음).

A · 지도 우선 (미니멀)

지도를 최대로. UI는 최소화하고 리뷰는 얇은 핸들 하나로 축소. 지도 탐색에 집중.
전체화면으로 보기 →

B · 바텀시트 중심

지도 상단 56% + 하단 리뷰 시트 기본 노출. 리뷰를 많이 보는 사용자에 적합.
전체화면으로 보기 →

C · 상단바 + 전체지도 추천

상단 로고바 + 실제 필터탭(전체/사진/내레벨/내주변), 우측 FAB 스택, 하단 핸들. 지도앱과 가장 유사한 표준 패턴.
전체화면으로 보기 →

D · 플로팅 통합

전체 지도 위 둥근 검색 pill + 우측 FAB. 하단은 리뷰+네비를 둥근 카드 1개로 통합해 적층 제거.

기능 동일 원칙: 4개 시안 모두 현재 PC 웹과 같은 기능(매운맛 레벨 범례 · 내 위치 · 리뷰 4탭 필터 · 제보 · 마이 · 로그인)만 씁니다. 지도 검색처럼 PC에 없는 기능은 넣지 않았습니다 — 배치만 바뀝니다.
공통 개선점 (현재 mapmadmap 대비): 하단에 흩어진 범례·내위치·네비·시트 4중 충돌 → 상단(로고/필터)·우측(FAB 스택)·하단(시트 1개)으로 영역 분리.
참고 서비스: 거지맵(가격 마커=매운맛 레벨 마커 대응), 야장맵(비강제 온보딩), 카카오·네이버·구글 지도(우측 FAB + 하단 시트 배치).
※ 지도는 mock(가짜 배경)이며 마커·리뷰는 예시 데이터입니다. 레이아웃 구조 비교용입니다.
